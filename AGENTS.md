# Dark Player Architecture Guide

Dark Player is a multi-module Kotlin & Jetpack Compose Android video studio built around Media3 ExoPlayer, NextLib FFmpeg decoders, and a custom AGSL Liquid Glass navigation engine.

- Package namespace: `dev.xboyrex.darkplayer`
- Author: **ㅤᏞᴀᴢʏㅤᎷꫝʏᴀɴк まやんく** (`@xboyrex`)
- Modules: `:app`, `:core:common`, `:core:data`, `:core:database`, `:core:datastore`, `:core:domain`, `:core:media`, `:core:model`, `:core:ui`, `:feature:player`, `:feature:playlist`, `:feature:videopicker`, `:feature:settings`, `:feature:network`.
