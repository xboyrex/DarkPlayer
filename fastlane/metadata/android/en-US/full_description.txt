<p>Dark Player is a high-control Android video player for your local media library and network sources. It combines a folder-first library with configurable playback controls and a focused, dark interface.</p>

<p><b>Playback</b></p>
<ul>
<li>Media3-based playback with FFmpeg-backed format support through NextLib</li>
<li>Hardware, Android system, and FFmpeg software decoder choices</li>
<li>Multi-track audio and subtitle selection, including embedded ASS/SSA styling</li>
<li>Playback speed control from 0.25x to 4.0x</li>
<li>Hardware LoudnessEnhancer volume boost up to 200%, where supported by the device</li>
<li>Seek, brightness, and volume gestures with directional locking</li>
</ul>

<p><b>Library and playback workflows</b></p>
<ul>
<li>Folder-first local video browsing with media counts and storage information</li>
<li>Custom playlists and M3U import</li>
<li>Picture-in-Picture and background audio playback</li>
<li>SMB, FTP, SFTP, and WebDAV network browsing and streaming</li>
<li>External playback intents with configurable HTTP headers</li>
</ul>

<p><b>Personalization</b></p>
<ul>
<li>System, Light, Dark, and AMOLED appearance modes</li>
<li>Color palette options and configurable player controls</li>
<li>Storage analyzer and cache management tools</li>
<li>Optional GitHub Releases update checker</li>
</ul>

<p>Dark Player is open source under GPL-3.0. See the source code and report issues on GitHub.</p>
<p>Network access is used for user-configured network media and release update checks. See the project privacy policy for the developer's privacy statement.</p>
